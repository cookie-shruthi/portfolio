Wiring and Configuring the SO101 Arms:

First, I learned about the difference between wiring in VEX robots, which I have worked on in the past(Direct connections between the brain and the motors), and the wiring in the arms (I2C).

I2C is a two-wire serial communication system, or in other words, a system where, in this case, the motors are connected to the brain.

12A

In this case the I2C Master represents the “Brain” (Motor control board) while the 6 motors for each arm act as the slaves.

13A

13B

In the motor control board the green port is for power, the beige for the serial wires, and the metallic for the computer wire. On the power terminal (green power), there was no place to connect the power source wire. Instead, I had to use a power source adapter, and using the bottom of the board to identify the positive and negative sides, I was able to connect the red wire to positive and the black wire to negative (universal DC wiring).

15A

I connected the wires to each of the servos to prepare it for programming (15A).

16A

I connected my motor controller terminal to my computer and a power source and initialized it with the command lerobot-find-port. The port of this MotorsBus is '/dev/tty.usbmodem5B7A0000581' (16A).

I used the following command to set up the motor ids. I used the port from the previous step for the following command:

lerobot-setup-motors \

    --robot.type=so101_follower \

    --robot.port=/dev/tty.usbmodem5B7A0000581

18B

I followed the same steps to assign IDs to the motors in the leader arm. The port for the motor controller board for the leader arm is /dev/tty.usbmodem5B7A0003391. An issue I faced while doing this was a voltage error (18B), after experimenting I discovered that this occurred because the power source for the Follower arm has more voltage than that of the Leader arm.

After this, I started calibrating the follower and leader arm. This is important because it allows the computer to know and compare the range of motion for both arms, which will allow you to teleoperate the arms (control the follower arm using the leader arm).

To calibrate the follower arm (19A) I used the following command:

lerobot-calibrate \

    --robot.type=so101_follower \

    --robot.port=/dev/tty.usbmodem5B7A0000581 \

    --robot.id=cookies_follower_arm

19B1

After calibrating the arms I set up the teleoperating system using the following:

lerobot-teleoperate \

    --robot.type=so101_follower \

    --robot.port=/dev/tty.usbmodem5B7A0000581 \

    --robot.id=cookies_follower_arm \

    --teleop.type=so101_leader \

    --teleop.port=/dev/tty.usbmodem5B7A0003391 \

    --teleop.id=cookies_leader_arm

An issue I faced while doing this is that the terminal responded that it only recognized motor 1 and was unable to recognize the other 5 motors. This occurred because of a connection issue between motors 1 and 2, and because the motors are connected serially this made it so that the interrupted connection affected all 5 other motors. I fixed this by examining all the wiring connections and making sure everything was connected and operating as expected.

Some issues that I still saw during the process was that, although the previous calibration issue (claw not closing properly) was fixed, the claw was still not able to close fully due to physical limitations (the claw itself can not close because of motor range and parts interfering with one another). In addition, the arm is unable to reach the ends of larger pieces (and many normal pieces) of clothing due to its limited range of motion.
